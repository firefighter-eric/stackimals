# Stackimals 项目文档

这里记录 Stackimals 当前版本的产品事实、工程边界和发布要求。文档面向产品、设计、开发、测试和后续接手项目的自动化代理。

## 当前基线

- 产品版本：`0.1`，单人玩家对 Milo AI
- 实现基线：15 动物、双方各 3 次换动物、连续旋转与多设备自适应版本
- 最后核对：2026-08-22
- 部署形态：Vite 静态站点，部署到 Vercel

## 状态定义

文档中使用以下标签：

- **当前要求**：当前产品必须保持的行为；修改前需要明确产品决策。
- **实现约束**：当前代码依赖的工程条件；可以重构，但不能在没有等价验证的情况下删除。
- **验收门槛**：合并或发布前必须达到的结果。
- **当前不做**：不属于 `0.1` 版本，不能在普通修复中顺带扩大范围。
- **已知限制**：已经确认但尚未实现或覆盖的能力，不应被描述为已完成。

## 文档维护规则

以下变化必须在同一个变更中更新对应文档：

1. 修改胜负、回合、计分、队列或暂停规则时，更新产品要求及规则测试。
2. 修改画布尺寸、平台、危险线、出界、稳定判定或 Matter 参数时，更新边界条件及物理回归测试。
3. 增删动物或替换动物图片时，更新资源清单、碰撞轮廓、几何测试和版权说明。
4. 修改 AI 行为、难度或随机性时，更新 AI 边界及确定性测试。
5. 增加账号、存档、排行榜、联网对战或后端时，先更新产品范围和数据/安全边界，再实现。
6. 修改部署方式或 Vercel 配置时，更新发布清单和根目录 `README.md`。

当文档和代码不一致时，以测试通过的当前代码行为作为诊断依据，但不应静默接受偏差；需要判断是修正文档还是修复实现，并在变更说明中写清楚。
